`vector-preview.svg` is an original synthetic scene authored for Render.NET. It contains no imported artwork, fonts or external resources. It exercises local symbols, elliptical and Bezier geometry, gradient transparency, clipping, group opacity, CSS classes and dashed strokes. It is covered by the repository's MIT license.

`filter-reference.json` contains 352 original SVG scenes and SHA-256 hashes of their straight RGBA output from Render.NET.Svg 0.3.18, commit `9a8bf825e33e8e46c76df261ebae42dda49ba8b2`. They exercise Gaussian blur and morphology with translucent overlapping colors, transparent input, zero/fractional/oversized radii, all blur edge modes, sRGB/linearRGB, reflections, right-angle rotation and oblique rotation. Render at 31 × 23, supersampling 1. These fixed references check the optimized implementation against the previous renderer, independently of its new scanline algorithms. No external artwork or rendering implementation was imported.

`effects-preview.svg` is the original Render.NET effects demonstration also used by Cotton's SVG preview tests. Its 2560 × 1536, supersampling 1 render has a 20-second cancellation deadline and a fixed 0.3.18 RGBA hash in `SvgFilterRegressionTests`.
