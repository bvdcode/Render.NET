Fifteen Telegram TGS regression inputs provided with permission for use as test cases. `manifest.json` records the SHA-256 of every compressed input. Filenames identify the feature exercised.

Strict rendering tests cover hidden video layers, translucent group paint scopes, simultaneous trim paths across styled subgroups, controller metadata, identity hue/saturation, an empty puppet mesh, legacy Gaussian Blur and alpha Set Matte. Active expressions and Roughen Edges are additional regression cases.
